# Claude Architecture Toolkit

Open-source skills and tools that make Claude useful for real architecture and design work.

**Status:** early stage. The first skills are in progress.

## Why

AI tools are strong at code and writing, but still weak at architecture: plans, diagrams, renders and design thinking. This toolkit aims to close that gap for architecture students and designers.

## Planned skills

- Floor plans, sections and elevations as clean, scaled vectors (SVG, DXF, PDF)
- Analysis and concept diagrams: site, sun path, climate, circulation, program, massing
- Zoning diagrams from floor plan images
- Render direction and post-production for architectural visualization
- Presentation
